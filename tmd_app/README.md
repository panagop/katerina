# Εφαρμογή Streamlit για TMD

Διαδραστική εκδοχή της ανάλυσης του `tmd_parametric/`. Το μοντέλο OpenSees, οι
σχέσεις Tsai & Lin και ο υπολογισμός των μεγεθών απόκρισης δεν ξαναγράφονται:
το `core.py` εισάγει απευθείας τα modules του `tmd_parametric/`.

```bash
cd tmd_app
uv run --project .. streamlit run streamlit_app.py
```

Έλεγχοι (AppTest, χωρίς browser· ελέγχουν και τις τιμές αναφοράς El Centro / αρμονικής):

```bash
uv run python -X utf8 -m pytest tmd_app/tests
```

## Σελίδες

| Σελίδα | Περιεχόμενο |
|---|---|
| Διέγερση | El Centro (προεπιλογή), αρχείο του χρήστη ή αρμονική. PGA, διάρκεια, διάγραμμα |
| Κατασκευή & TMD | m, T, ξ, m̂. Βέλτιστα f, ξd κατά Tsai & Lin ή τιμές του χρήστη |
| Ανάλυση | Χωρίς / με TMD: u_max, RMS, διαδρομή TMD, χρονοϊστορίες, λήψη csv |
| Παραμετρική | Σάρωση m̂, f/f_opt, ξd/ξd,opt για την επιλεγμένη διέγερση, ή ρ (αρμονική) |

## Αρχείο επιταχυνσιογραφήματος

Αρχείο κειμένου σε μία από τις μορφές:

- **t, a**: δύο στήλες χρόνος-επιτάχυνση (όπως το `elCentro.txt`). Το dt
  προκύπτει από τα δεδομένα και πρέπει να είναι σταθερό.
- **a**: μία στήλη επιταχύνσεων. Δίνεται το dt.
- **πολλές**: πολλές τιμές ανά γραμμή, ανάγνωση κατά γραμμή (π.χ. PEER `.AT2`,
  με 4 γραμμές επικεφαλίδας). Δίνεται το dt.

Οι μονάδες του αρχείου (g, m/s², cm/s²) μετατρέπονται σε m/s² κατά την ανάγνωση.
