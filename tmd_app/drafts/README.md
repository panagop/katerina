# Προσχέδια

Τα `test1.py`, `test2.py`, `test3.py` είναι διαδοχικά προσχέδια της καρτέλας «Εύρεση
Βέλτιστων» της σελίδας `app_pages/parametric.py`. Κρατούνται μόνο για αναφορά: δεν τρέχουν
μόνα τους (χρησιμοποιούν μεταβλητές της σελίδας, π.χ. `tab_opt`, `structure`, `ground`) και
η τελική μορφή είναι στο `parametric.py`.

- `test1.py`: αναζήτηση με κριτήριο μόνο το u_max, με το ξ της κατασκευής.
- `test2.py`: προστίθεται πεδίο ξ για την αναζήτηση.
- `test3.py`: προστίθεται ο έλεγχος στον χρόνο με τα βέλτιστα.
